# archive/

Неиспользуемые ассеты, вынесенные из `src/assets/`.

**На прод не попадают.** Vite кладёт в `dist/` только то, что импортировано из `src/`,
плюс содержимое `public/`. Всё, что лежит здесь, не входит ни в то, ни в другое —
`npm run build` эту директорию не видит. Prod-контейнер (`docker-compose.prod.yml`)
раздаёт только `./dist`.

Файлы оставлены в репозитории, а не удалены: исходники могут пригодиться для
портфолио или маркетинга.

Чтобы вернуть файл в работу — перенести обратно в `src/assets/...` и
импортировать в компоненте. Без импорта файл в сборку не попадёт.
